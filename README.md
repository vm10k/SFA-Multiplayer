## 🌟 Key Features

* ⚡ **High-Performance Netplay**: Low-latency lockstep engine powered by WebRTC DataChannels with automatic WebSocket relay fallback and live millisecond ping monitoring.
* 👥 **Versatile Battle Formats**: Jump into 1v1 Ranked Duels, 2v2 Dramatic Battles, 3v3 Team Survival, or solo VS COM training.
* 🕹️ **Universal Gamepad & Fightstick Engine**: Native support for PS5 DualSense, PS4, Xbox Series/One, Switch Pro, and PC Arcade Fightsticks with in-game key rebinding.
* 💬 **Social Arena Hub**: Live global chat, interactive friends list, direct 1v1 challenge invites, rival match dossiers, and profile avatars.
* 🎨 **Open Character Modding**: Create, map, test, and import new fighters and heroes using the integrated browser-based Character Studio.
* 📱 **Mobile Virtual Controls**: Complete on-screen arcade stick and 6-button touch layout for landscape smartphones and tablets.

## 🏗️ Technical Highlights

* **WebRTC Peer-to-Peer**: Direct client-to-client DataChannels eliminate central server processing bottlenecks for instant input delivery.
* **Deterministic Synchronized RNG**: Shared random number seeds ensure frame-perfect physics and projectile collision synchronization across all clients.
* **Smart WebSocket Relay Fallback**: Automatically switches to low-overhead WebSocket relay mode if symmetric NAT or firewall blocks P2P handshakes.
* **Responsive 2K / 4K Upscaling**: Dynamic CSS letterboxing preserves crisp pixel-art sprites up to 3840×2160 displays with zero stretching.
